## 与规格不一致 / 未验证

- `docs/spec/lifecycle.md` 写的是「codex 简报轮结束后 composer idle」，本次按派单改成「首轮已被接受」（简报回显或 thread 行）。规格文本需派单方同步，代码以派单为准。
- 同 pane 重复记录的退休只有单测覆盖。真机复现需要 codex 在首轮自己执行 `sbb adopt`，而新简报正是要阻止它，无法在真实 spawn 中稳定构造。单测用真实的 `listBrains` / `removeBrain` 走完整落盘与退休路径，并断言不同 pane 的记录不受影响。
- `readCodexTrust` 只做精确路径匹配（与 codex 自身一致）：`[projects."/private/tmp"]` 不覆盖 `/private/tmp/sub`，有单测。
