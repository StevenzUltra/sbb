# M2 h1 小修报告：`--cli-args` 的短横线值

分支 `m2/h1-cli-args`，base `origin/main` = `baaa1d0`。派单 msgId `7e3046d0`。

## 问题

`sbb spawn --cli-args "--permission-mode bypassPermissions"` 被 `util.parseArgs` 判成 ambiguous（值以 `-` 开头），只有 `--cli-args="…"` 能用。

## 改动

`src/cli/spawn.js`：新增 `normalizeCliArgs()`，在 `parse()` 前把「裸 `--cli-args` + 下一个 token」改写成 `--cli-args=<值>`；只有当下一个 token 是 spawn 自己的选项（`--name` … `--help`）时才不吞。help 里的示例改为 `--cli-args="<extra>"`，并写明两种写法都可用。共享的 `src/cli/util.js` 未改动，避免影响其他命令。

## 验证

- `npm test`：346 pass / 0 fail（新增 5 个在 `test/cli-spawn.test.js`）。
- 真机（scratch `tmux -L sbb-h1` + `SBB_DIR=/tmp/sbb-h1-acc4`，账户 a）：

```
$ sbb spawn --name cliargs --role main --account a --cli claude --cwd /Users/steven/developer/eagerstudy --cli-args "--verbose"
spawned SSL-0001 cliargs acc:2.1
1.206 total   exit=0
$ ps -o command= -p <pane pid>
claude --append-system-prompt-file /tmp/sbb-h1-acc4/briefs/SSL-0001.md --verbose
```

`--cli-args="--verbose"` 走单测覆盖（同一 `normalizeCliArgs` 分支），两种写法在 `run()` 端到端测试里都断言 `extraArgs` 原样到达 `spawnBrain`。收尾已 `kill --yes` 并清理 scratch 服务器与临时目录。

## 边界

裸 `--cli-args` 后面直接跟 spawn 自己的选项（如 `--cli-args --force`）仍按缺值处理，`parseArgs` 报错 → exit 2，有单测。
