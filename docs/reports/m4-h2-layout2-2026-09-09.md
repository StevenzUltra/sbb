## 交付内容

### 1. 顶栏 44 px（`web/src/components/TopBar.vue`）
只有视图下拉（线性图标、无填充）、⌘K 搜索框、设置齿轮。删掉了 logo、"SBB / Switch Brain Brain" 字样、额度 chip、策略开关、待批准计数、主题切换和「新建」。下拉四项目：控制台 / 组织图 / 回执日志 / 设置，快捷键 ⌘1..⌘4 与 ⌘,。顶栏保留 `bar` 类以接住桌面壳的 `-webkit-app-region: drag` 与左侧 86 px 留白，内部控件用 `no-drag` 收回。

### 2. 状态栏 30 px（`web/src/components/StatusBar.vue`，替换 TpsBar）
连接点、吐字（选中脑 + 合计）、每账号周额度、主脑互通、待批准红色胶囊、版本号，单行 `overflow-x-auto`。额度超过四个折叠成 `+N ▾`，点击展开浮层。主脑互通点击循环 开 / 审核 / 关。`web/src/components/TpsBar.vue` 已删除。

### 3. 设置页（`web/src/components/SettingsView.vue`）
`view: 'settings'`，齿轮或 ⌘, 进入。左侧导航：互通与策略 / 额度 / 启动器 / 账户 / 终端 / 外观（外加「关于 SBB vX.Y.Z」）。所有控件读 `store.policy`，写 `POST /api/policy`；线形状集中在 `web/src/lib/policy.js`（UI 词表 开/审核/关 与 wire 的 `on|moderated|off` 互转）。新键按任务单形状实现：`spawnPreamble {cli,value}`、`spawnCommand {cli,value}`、`spawnShell value`、`terminal`、`subsDirect`。外观页主题三选（深色/浅色/跟随系统），桌面壳下额外显示 `--sbb-tint-alpha` / `--sbb-blur` 两个滑杆，值写 localStorage（`web/src/lib/appearance.js`），`main.js` 挂载前先应用，避免闪白。

### 4. 「新建」
脑图头部新增 `+ 新建` 按钮，空状态、SpawnDialog 标题与提交按钮、spawn toast 全部由「开脑」改为「新建」。

### 5. 保留项
可拖拽列宽、组频道、实时面板、回执、组织图、待批准卡片、桌面半透明模式均保留；半透明改为读 CSS 变量（`web/src/style.css` 中 `rgba(10,13,11,var(--sbb-tint-alpha))` 与 `blur(var(--sbb-blur))`）。

## 待派单方处理（服务端缺口）

`src/ui/server.js` 的 `policy()` 还没有新键的 argv 映射。对运行中的 `sbb ui` 实测：

```
{"spawnPreamble":{"cli":"claude","value":"echo preflight"}} -> 400 invalid_input:
  "peers, set, allow, deny, quota or spawnArgs is required"
{"terminal":"ghostty"}   -> 400（同上）
{"subsDirect":false}     -> 400（同上）
{"spawnShell":"/bin/zsh"}-> 400（同上）
{"quota":{"floorWeekly":12}} -> 200（现有键正常写入）
```

`src/policy/config.js` 已经能承载 `spawn.preamble/command/shell`、`terminal`、`teams.subsDirect`，缺的只是 server 侧解析。前端已按任务单形状发出请求，被拒时以 toast 呈现、不静默；fixture 侧 `applyPolicy` 已按服务端应有映射实现，服务端补上后无需改前端。真实模式那一条 400 console 错误即来自这次被拒的写入，属预期。
